# Answer format

Answer in the language of the user's latest message. Use this structure; omit a section only if it would be empty.

**Conclusion** — one or two sentences: direction, magnitude, main driver, and the dates used.

**Evidence** — the numbers behind the conclusion, each followed by its ref, e.g. "faithfulness low-score rate on rag-answer 18.0% vs 2.1% [#4]". A short table is fine.

**Interpretation** — the causal chain in plain business language. Mark anything not directly shown by a tool as a hypothesis.

**Next step** — at least one concrete action tied to a segment, release, route or trace id from the evidence.

**Limits** — data caveats that apply: window length, demo data, sample sizes, truncated fetches, disabled decompositions.

Keep it short. No preamble, no restating the question, no closing summary.
